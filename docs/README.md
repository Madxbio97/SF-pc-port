## Repository ownership

| Path | Contents |
| --- | --- |
| `apps/` | Executables and ROM-gated diagnostic probes |
| `include/sf/`, `src/` | Project-owned runtime and platform code |
| `assets/` | Distributable launcher, dossier and localization assets |
| `tests/` | Deterministic tests |
| `cmake/`, `tools/` | Build, validation, packaging and generation tools |
| `external/PsyCross/` | Vendored third-party backend with local changes |
| `docs/releases/` | Immutable release-specific notes |
| `build/`, `out/`, `dist/` | Generated local output; never source material |

## Historical research

`STAGES.md`, `M1_FINDINGS.md`, `STAGE*_FINDINGS.md` and `H*_FINDINGS.md` record
completed or superseded investigation. They are not current plans.

## Generated reference

`RUSSIAN_LOCALIZATION_REVIEW.txt` and `.tsv` are generated by:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass `
  -File tools/export_localization_review.ps1
```

Do not edit generated files manually.

## Maintenance rules

- Keep release-specific prose in `docs/releases/<version>.md`.
- Keep the aggregate public history in `CHANGELOG.md`.
- Do not hard-code the current release number in general documentation.
- Keep README feature summaries short; implementation detail belongs in focused
  documents, tests or findings.
- Preserve historical release notes except for factual or link corrections.
