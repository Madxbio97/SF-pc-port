# Syphon Filter PC - Public Test 0.1.0-PT8

Windows x64 public-test package for the USA v1.1 release of *Syphon Filter*
(`SCUS-94240`).

## Download

- `SyphonFilterPC-0.1.0-public-test.8-win64.zip`
- `SyphonFilterPC-0.1.0-public-test.8-win64.zip.sha256`
- Verify the ZIP against the SHA-256 sidecar before extracting it.

## Highlights

- Fixed streamed VRAM page, CLUT and mission-bank ownership so actors remain
  visible and each segment receives its authored textures.
- Replaced the fixed texture-alias pool with generation-aware storage and kept
  strict diagnostics for genuinely invalid scene state.
- Added an opt-in Surface Picker for magenta surface selection and complete
  per-surface diagnostic dumps.
- Refactored the retail 120 Hz SPU/CD/DMA timeline and OpenAL buffering so audio
  remains synchronized independently of a 20 Hz game simulation and rendering
  rates up to 240 FPS.
- Added dynamic scene lights and geometry-based character shadows with stable
  projection across floors and walls.
- Restored original English scope labels and made button prompts display the
  current keyboard, mouse or gamepad binding in both locales.
- Prevented Russian mission-objective overrides from leaking into English
  pause-menu sessions.
- Restored the original retail cheat activation paths and an Options > Cheats
  page while removing launcher-side mission and cheat bypasses.
- Extended regression coverage for VRAM streaming, audio timing, localization,
  input prompts, lighting, shadows and pause-menu behavior.

## Validation

- Both Windows Release build trees completed successfully.
- Core tests passed 18/18 and PsyCross tests passed 21/21.
- Configured headless ROM probes passed 13/15. The two remaining optional
  diagnostics reproduce on `origin/main`: the G3 actor-coverage probe reports
  the historical mission 14/15 gaps, and the PARK2 environment probe still
  lacks its expected flame/backdrop signature. Neither failure is introduced
  by this release.
- The package audit verified internal and external SHA-256 manifests, the
  executable, locales, dossiers and forbidden-file policy.
- The interactive game was not launched during automated validation.

## Important

The package does not contain the original game. Select a legally obtained
BIN/CUE image of *Syphon Filter* USA v1.1 in the launcher. Other revisions are
not supported.

The archive is a clean installation: it contains no saves, launcher settings,
disc image, logs or `syphon_filter_cheats` developer marker.
