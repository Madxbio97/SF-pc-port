# Syphon Filter PC - Public Test 0.1.0-PT12

Release date: 2026-07-28

## Files

- `SyphonFilterPC-0.1.0-public-test.12-win64.zip`
- `SyphonFilterPC-0.1.0-public-test.12-win64.zip.sha256`

## Changes

- Blocked native and guest locomotion throughout first-person aim, including
  the transition edge, so simultaneous WASD and aim cannot corrupt Gabe's
  collision root.
- Rejected first-person transitions during rolls, recovery actions and radio
  conversations; unsafe held input must be released before it can re-arm.
- Limited Circle-in-aim to the original optic zoom behavior for scoped rifles.
- Extended scene lighting to ordinary trigger props and added a safe HMD
  back-color fallback for interactive objects.
- Regenerated Russian font sheets with clean bilinear cell gutters, corrected
  vertical alignment and briefing-frame containment.

## Validation

- Windows MSVC and PsyCross Release builds.
- Complete non-ROM CTest suites.
- Deterministic Russian font-atlas regeneration.
- Release-package manifest, internal/external hash and forbidden-file checks.

The package does not include the original game. A legally obtained BIN/CUE image
of *Syphon Filter* USA v1.1 (`SCUS-94240`) is required.
