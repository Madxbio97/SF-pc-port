# Syphon Filter PC 0.1.0 GMD normals test 1

## Changes

- Decodes the retail signed-byte GMD normal table and per-corner normal
  indices.
- Uses authored Gouraud normals for regular and near-clipped GMD lighting.
- Derives the normal-table length from triangle references and ignores
  unrelated trailing HOG payload.
- Removes faceted lighting wedges from cylindrical props such as the
  Kazakhstan missiles, warheads and oil barrels.

## Verification

- All 1,147 campaign GMD payloads were audited for table bounds and indices.
- Mission 8 (Base Bunker) passed headless asset inspection.
- Release targets syphon_filter and sf_tests compiled successfully.
- sf_tests passed.
- The game executable was not launched.
