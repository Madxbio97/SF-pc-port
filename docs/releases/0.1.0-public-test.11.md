# Syphon Filter PC - Public Test 0.1.0-PT11

Release date: 2026-07-28

## Files

- `SyphonFilterPC-0.1.0-public-test.11-win64.zip`
- `SyphonFilterPC-0.1.0-public-test.11-win64.zip.sha256`

## Changes

- Removed the experimental screen-space contact-shadow/SSAO implementation.
- Removed the corresponding launcher option, configuration field and command
  line switches.
- Removed the SSAO shaders, intermediate render targets and post-processing
  pass, reducing GPU work and renderer state transitions.
- Preserved the PT10 renderer hot-path optimizations and geometry-driven
  dynamic shadows for Gabe, allies and enemies.

## Validation

- Windows PsyCross Release build.
- Complete non-ROM CTest suite.
- Release-package manifest, hash and forbidden-file checks.

The package does not include the original game. A legally obtained BIN/CUE image
of *Syphon Filter* USA v1.1 (`SCUS-94240`) is required.
