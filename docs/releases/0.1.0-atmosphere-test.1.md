# Syphon Filter PC 0.1.0-atmosphere-test.1

## Graphics test

- Removed the rejected fullscreen GTAO/SSAO experiment.
- Replaced the fullscreen fog overlay with an optional per-fragment atmosphere
  pass inside the primary PSX material shader.
- Fog now follows each world primitive's PGXP depth before transparency is
  composited, while HUD, letterbox and optic overlays remain untouched.
- The effect can be disabled with **Volumetric fog** in the launcher or
  `--no-volumetric-fog`.
