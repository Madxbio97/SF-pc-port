# Опись правок Syphon Filter PC за 16 ноября 2026 года

Дата и время ниже — Москва, UTC+3. Составлено по истории Git.
В релиз 0.2.0 Beta.3 входят итоговые игровые изменения 17 коммитов
от `f7bc273` до `50636bc` включительно, поверх `a11020b` (public-test.29).
Промежуточные доработки объединены по итоговому поведению. Версия и упаковка
Beta.3 оформлены отдельным релизным коммитом; его полный номер указан в
`BUILD_INFO.txt` внутри архива.

## Реализованные изменения

### Попадания и опасность

- [x] ~~Попадания через стены~~ — для вражеских пуль проверяется фактическая
  линия между стрелком и Гейбом, включая прямые и дальние варианты обработки
  урона и режим прицеливания от первого лица.
- [x] ~~Устаревшая проверка видимости~~ — позиция стрелка проверяется после
  перемещения противника, чтобы прежняя видимость не разрешала новый выстрел.
- [x] ~~Опасность за укрытием~~ — индикатор учитывает преграду, а не продолжает
  накапливаться только из-за наличия вооружённого противника.

### Стекло, дым и частицы

- [x] ~~Исчезнувшие эффекты~~ — возвращены исходные спрайты дыма, газового
  облака и взрывных частиц в соответствующие проходы отрисовки.
- [x] ~~Осколки стекла~~ — добавлена обработка текстурированных треугольных
  осколков, их страниц текстур и палитр.
- [x] ~~Вылет при выстреле в стекло~~ — исправлен общий контракт передачи
  таких примитивов между оригинальным кодом и нативным рендерером.

### Гейб и приближение камеры

- [x] ~~Прозрачность вблизи камеры~~ — используются исходные пороги PSX и
  флаги модели; исправлено преобразование вертикальной координаты корня.
- [x] ~~Внутренние грани~~ — восстановлено отсечение обратных граней HMD.
- [x] ~~Другие части тела сквозь прозрачную модель~~ — отдельный проход
  собственной глубины оставляет видимой ближайшую поверхность модели.
- [x] ~~Срез ближайшей поверхности головы~~ — исправлены ближняя плоскость
  актёра и сохранение дробных координат пересечений. Глубина мира
  восстанавливается для следующих прозрачных эффектов.

### Цвет, атмосфера и освещение

- [x] ~~Более тёмная гамма~~ — скорректированы яркость и контраст сцены,
  добавлены стабильный дизеринг и небольшое монохромное зерно.
- [x] ~~Резкие переходы градиентов~~ — смягчены переходы освещения и цвета
  поверхностей; HUD и аддитивные эффекты имеют отдельную обработку.
- [x] ~~Атмосфера уровней~~ — восстановлена передача оригинальных экранных
  фильтров и атмосферных примитивов. Авторские PC-скайбоксы отключены по
  умолчанию, доступна исходная подложка PSX.
- [x] ~~Цветовые разводы Казахстана~~ — убрано жёсткое раздельное квантование
  каналов атмосферного градиента перед его сложением со сценой.
- [x] ~~Фонарик и прожекторы~~ — освещение использует исходную проекцию PSX,
  а не проекцию PC-камеры, которая чрезмерно сужала пятно света.
- [x] ~~Цвета источников и насыщение~~ — восстановлены исходные маски каналов,
  округление и сложение цветов, включая цветные миссионные источники.

### HUD, широкий экран и меню

- [x] ~~Радар~~ — используются исходные контакты, цвета, затухание, отметки
  тревоги и указатели, а не приближённое построение по расстоянию.
- [x] ~~Широкоформатный HUD~~ — к краям видимой области привязаны полосы
  состояния, радар, дополнительные показатели, оружие и боезапас.
- [x] ~~Таймер~~ — перемещается к левому краю вместе с радаром.
- [x] ~~Верхняя полоса выбора оружия~~ — подложка и рамка продолжаются до
  обоих краёв экрана; центральный слот и силуэты сохраняют пропорции.
- [x] ~~Меню паузы и сообщения~~ — адаптированы области меню, нижние сообщения,
  подложки и доступная ширина подсказок. Исправлены привязки счётчика кадров.
- [x] ~~Анимации интерфейса~~ — восстановлена постепенная выдача текста меню
  и повтор регулировки звуковых ползунков при удержании кнопки.
- [x] ~~Демонстрационный режим~~ — возвращено воспроизведение исходных DEM
  из главного меню при бездействии.

### Оружие, музыка и звук

- [x] ~~Хват оружия после восстановления~~ — повторяется исходное оснащение
  оружия и его поза при переносе инвентаря/перезапуске контрольной точки.
- [x] ~~Музыка контрольной точки~~ — восстанавливается соответствующая
  музыкальная команда оригинального проигрывателя.
- [x] ~~Тихие и зацикленные музыкальные фрагменты~~ — исправлено состояние
  автоматического изменения громкости SPU.
- [x] ~~Щелчки при нехватке аудиоданных~~ — добавлены плавное затухание и
  восстановление потока вместо резкого скачка к тишине.

Стык Washington Park нельзя считать окончательно подтверждённым на слух:
автоматическая проверка непрерывности PCM не заменяет прослушивание пользователем.

### Производительность и диагностика

- [x] ~~Выделения памяти для точных координат каждый кадр~~ — таблицы вершин
  переиспользуют память и сбрасываются по поколениям.
- [x] ~~Двойная регистрация вершин~~ — координаты HMD и обрезанных треугольников
  регистрируются один раз на конечных адресах.
- [x] ~~Повторный опрос ввода при рисовании HUD~~ — события не опрашиваются
  заново на каждой букве внутри уже открытого кадра.
- [x] ~~Повторное освещение общих вершин~~ — результат переиспользуется внутри
  прохода секции; новая секция и новые данные цвета получают свежий расчёт.
- [x] ~~Воспроизводимая сверка света~~ — добавлена отдельная ROM-диагностика
  всех 20 миссий и регрессии точности/сброса кэшей.

## Релизная подготовка Beta.3

- [x] ~~Версия сборки~~ — обновлены версия проекта, свойства EXE и версия
  упаковщика; полный исходный коммит записывается в BUILD_INFO.txt.
- [x] ~~Состав пакета~~ — опись включена отдельным файлом, предусмотрены
  внутренняя ведомость SHA-256 и контрольная сумма архива.
- [x] ~~Упаковщик~~ — лицензии берутся из фактического каталога зависимостей
  CMake; наличие лицензий и примечаний проверяется до создания пакета.

## Подтверждённые автоматические результаты

- Release portable: **24/24** теста.
- Release PsyCross: **28/28** тестов, включая проверки GPU.
- Освещение: **57 344** сэмпла из начальных сцен **20 миссий**, ноль
  расхождений с выполненными оригинальными инструкциями R3000/GTE.
- Нативная передача исходной проекции света проверена на всех 20 миссиях.
- Для оптимизаций совпали хэши координат и цветов проверенной геометрии.
- Для пакета проверяются внутренний SHA256SUMS, SHA-256 ZIP, соответствие EXE
  Release-сборке и отсутствие образов игры, сохранений, логов и отладочных файлов.

## Проверка пользователем

- [ ] Стрельба противника при нахождении Гейба за стеной, в том числе от первого
  лица; поведение индикатора опасности.
- [ ] Разбивание стекла: осколки, отсутствие вылета, корректные текстуры.
- [ ] Дым, обычная и газовая гранаты, взрывные частицы и их перекрытие сценой.
- [ ] Максимальное приближение камеры спереди и сзади: прозрачность, внутренние
  грани и ближайшая поверхность головы.
- [ ] Тёмные уровни и Казахстан: гамма, градиенты, атмосферные полосы и погодные
  эффекты; сирены и исходные цветные источники.
- [ ] Фонарик CAVE2, прожекторы базы Ромера и остальных миссий: пятно на полу,
  стенах и потолке, движение и дальность.
- [ ] Широкий формат: таймер, радар, полосы состояния, оружие/боезапас, вся
  подложка выбора оружия, меню паузы и нижние сообщения.
- [ ] Оружие и музыка после перезапуска контрольной точки; переходы и длительные
  музыкальные циклы, отдельно щелчок/треск Washington Park.
- [ ] Регулировка звука удержанием кнопки, выдача текста меню и деморежим.
- [ ] Статтеры при ходьбе, вращении камеры и переходах между помещениями.

Автоматические результаты не подтверждают прохождение всех комнат и скриптов,
полное визуальное совпадение каждого кадра с PSX или отсутствие всех оставшихся
дефектов. Геймплейное тестирование, как договорились, выполняет пользователь.
