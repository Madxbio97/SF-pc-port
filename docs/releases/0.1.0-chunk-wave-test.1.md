# Syphon Filter PC 0.1.0 chunk wave test 1

## Changes

- Selects one real one-ring visibility neighbour and starts its terrain
  lookahead before the retail room switch.
- Reveals the next chunk far-to-near along a fixed world-space axis over
  1.35 seconds, with a wider soft band and 90% of the sweep completed early.
- Renders lookahead terrain in an isolated depth phase: it self-occludes, then
  the active room clears and owns the final colour/depth image.
- Admits lookahead textures only after mandatory scene resources fit; an
  unavailable CLUT budget skips the optional preload without failing startup.
- Objects, collision, scripts and room ownership remain unchanged.

## Verification

- Release targets syphon_filter and sf_tests compiled successfully.
- sf_tests passed.
- The game executable was not launched.
