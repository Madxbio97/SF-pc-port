# Syphon Filter PC 0.1.0-public-test.26

Windows x64 public-test candidate built on 2026-08-07.

## Changes since public-test.25

- Added selectable Automatic, XInput, DirectInput and Raw Input controller
  backends with robust device discovery, hot-plug handling and controller-family
  prompt labels.
- Restored vibration from the retail motor commands and stopped it safely on
  pause, focus loss, disconnect, restart and scene teardown.
- Added physical gamepad rebinding to the launcher and in-game pause menu.
- Unified both rebind interfaces on one action catalog, preset table, validation
  path, conflict-swap rule and persistent `[ControllerBindings]` configuration.
- Apply and Resume now commit the layout; Cancel, closing the launcher subwindow
  and cancelling capture leave the committed layout untouched.
- Kept committed layouts active through Return to Title and made failed INI
  writes retry without interrupting gameplay.
- Restored first-person right-stick aiming, increased its response speed and
  preserved native-rate input samples across the 20 Hz retail update boundary.
- Switched service-message prompts between keyboard/mouse and the active
  controller family.

## Validation

- Windows x64 PsyCross Release build completed successfully.
- Full Release CTest suite passed: 41/41, including supported-ROM probes.
- The interactive game was not launched during automated validation.
