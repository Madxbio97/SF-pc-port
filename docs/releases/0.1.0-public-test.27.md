# Syphon Filter PC 0.1.0-public-test.27

Windows x64 public-test candidate built on 2026-08-07.

## Changes since public-test.26

- Stabilized DualSense navigation in the title and campaign-save menus with a
  menu-specific deadzone that suppresses neutral stick drift.
- Made the dominant stick axis win when both axes are active, preventing a
  smaller opposing-axis drift from reversing or holding menu navigation.
- Removed the redundant `FUEL TANK` meter from Agent-mode Freedom Memorial.
  Bomb-detonation tracking and Girdeux's tank weak-point mechanics are unchanged.

- The interactive game was not launched during automated validation.
