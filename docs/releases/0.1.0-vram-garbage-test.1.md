# Syphon Filter PC 0.1.0 VRAM garbage test 1

## Changes

- Anchors synthetic mip levels to the authored centre texel instead of using
  only sparse diagonal samples.
- Falls back toward the authored opaque texel when a mip footprint crosses
  transparent parts of a compact GMD texture island.
- Invalidates native texture-page residency after an unregistered
  LoadImage/MoveImage write so the authored page is restored immediately.
- Keeps registered SCRIM, lightbar and crate texture mutations as valid
  runtime content.

## Verification

- syphon_filter, sf_tests, sf_pgxp_precision_tests and
  sf_psycross_vram_tests compiled successfully.
- sf_tests, sf_pgxp_precision_tests and sf_psycross_vram_tests passed.
- The game executable was not launched.
