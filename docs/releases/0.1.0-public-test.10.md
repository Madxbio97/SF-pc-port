# Syphon Filter PC - Public Test 0.1.0-PT10

Windows x64 public-test package for the USA v1.1 release of *Syphon Filter*
(`SCUS-94240`).

## Download

- `SyphonFilterPC-0.1.0-public-test.10-win64.zip`
- `SyphonFilterPC-0.1.0-public-test.10-win64.zip.sha256`
- Verify the ZIP against the SHA-256 sidecar before extracting it.

## Highlights

- Added optional half-resolution, depth-aware SSAO without affecting the HUD.
- Removed synchronous OpenGL state queries from hot presentation paths.
- Changed guest VRAM synchronization from full texture uploads to coalesced
  dirty-row transfers and eliminated an intermediate framebuffer copy.
- Reused render scratch storage and primitive capacity plans across high-refresh
  presentation frames while preserving the original 20 Hz game simulation.
- Reduced SSAO sampling and blur bandwidth while preserving geometry edges.

## Validation

- Windows PsyCross Release configured and built successfully.
- All non-ROM CTest targets passed.
- Package contents, per-file hashes, external ZIP checksum and forbidden-file
  policy were verified without launching the interactive game.

## Important

The package does not contain the original game. Select a legally obtained
BIN/CUE image of *Syphon Filter* USA v1.1 in the launcher. Other revisions are
not supported.

The archive is a clean installation: it contains no saves, launcher settings,
disc image, logs or `syphon_filter_cheats` developer marker.
