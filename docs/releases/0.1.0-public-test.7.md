# Syphon Filter PC - Public Test 0.1.0-PT7

Windows x64 public-test package for the USA v1.1 release of *Syphon Filter*
(`SCUS-94240`).

## Download

- `SyphonFilterPC-0.1.0-public-test.7-win64.zip`
- `SyphonFilterPC-0.1.0-public-test.7-win64.zip.sha256`
- Verify the ZIP against the SHA-256 sidecar before extracting it.

## Highlights

- Added the complete Russian text-only language pack for all 20 missions,
  menus, briefings, objectives, parameters, gameplay messages, weapon text and
  baked map/title labels. Voices, music and FMV remain original.
- Rebuilt the Cyrillic sheets as a unified ViT-compatible 2x Industria-style
  atlas with corrected alignment and preserved retail layout metrics.
- Restored complete and correctly indexed mission briefings, the original
  two-page Weapons menu, full descriptions and weapon specifications.
- Fixed every observed `Grenade`/`Granade` pickup-message variant before ViT
  glyph encoding, eliminating pseudo-Cyrillic English text.
- Replaced the gameplay audio queue workaround with bounded continuous OpenAL
  callback streaming and stock-rate SPU scheduling.
- Added working VSYNC and an independent high-resolution frame limiter.
- Corrected launcher layout/Unicode labels, scene depth ordering, campaign flow,
  destructible restoration and the remaining pause-menu presentation paths.
- Refactored file I/O, localization, pause-menu data, VRAM and runtime validation
  into explicit modules guarded by automated architecture tests.

## Validation

- Both Windows Release build trees completed successfully.
- All non-ROM automated tests passed.
- The packaged locale is checked for its manifest, briefing/menu tables, weapon
  descriptions and three regenerated font sheets.
- The archive audit rejects saves, disc images, logs, cheat markers and
  developer artifacts.

## Important

The package does not contain the original game. Select a legally obtained
BIN/CUE image of *Syphon Filter* USA v1.1 in the launcher. Other revisions are
not supported.

The archive is a clean installation: it contains no saves, launcher settings,
disc image, logs or `syphon_filter_cheats` developer marker.
