# Syphon Filter PC 0.1.0-public-test.23

Windows x64 public-test candidate built on 2026-08-04.

## Changes since public-test.22

- Unified the first-person and auto-lock reticles under one precise frame.
  Reticle size now follows target depth, uses a smaller calibration and reacts
  faster while preserving soft positional follow.
- Made grenade throws reliable across the retail input-readiness gate.
- Restored short-lived, surface-aligned bullet impacts and PS1-style localized
  wound colouring, including reliable impacts while aiming in first person.
- Preserved the night-vision filter in tunnel environments and retained the
  restored moving-light and flashlight presentation.

## Package

- Windows x64 release with required runtime libraries and Russian locale.
- Internal per-file SHA-256 manifest and external archive checksum included.
- No game image, saves, settings, logs, cheat marker or developer artifacts.

Requires a legally obtained *Syphon Filter* USA v1.1 (`SCUS-94240`) BIN/CUE
image.
