# Syphon Filter PC - Public Test 0.1.0-PT14

Release date: 2026-07-30

## Files

- `SyphonFilterPC-0.1.0-public-test.14-win64.zip`
- `SyphonFilterPC-0.1.0-public-test.14-win64.zip.sha256`

## Changes

### Mission flow and localization

- Restored the authored mission-failure screen for scripted objective and
  parameter failures: original fade, type-on text and one reliable restart
  path replace the unlabelled black screen.
- Added complete Russian translations for mission-parameter and
  mission-objective failure messages, including partial type-on states.
- Polished mission startup with a calmer prompt reveal, a short transition into
  gameplay and correct composition of native and retail fades.

### Presentation and performance

- Corrected compact pickup sizing and made world callouts reveal and fade at a
  consistent speed from 30 through 240 presentation FPS.
- Added a smoothed presentation FPS and frame-time counter which reports host
  presentation performance independently of the original 20 Hz game logic.
- Split the monolithic PsyCross scene viewer into focused runtime, render,
  world, model, texture, HUD, pause, effects, save and presentation modules.
- Reduced repeated allocations and unchanged scene calculations while keeping
  renderer, audio and texture-residency behavior covered by regression tests.

## Validation

- Windows MSVC Release build and full test suite.
- Windows PsyCross Release build, full suite and supported USA v1.1 ROM probes.
- Release manifest, executable parity, internal/external SHA-256 and
  forbidden-file audit.

## Compatibility

The package requires a legally obtained BIN/CUE image of *Syphon Filter* USA
v1.1 (`SCUS-94240`). It contains no game image, saves, settings or cheat marker.
The release remains a public test and may contain compatibility issues.
