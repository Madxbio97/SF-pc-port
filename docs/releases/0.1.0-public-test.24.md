# Syphon Filter PC 0.1.0-public-test.24

Windows x64 public-test candidate built on 2026-08-06.

## Changes since public-test.23

- Added a localized three-level New Game selector: Normal, retail Hard Mode and
  the PC-exclusive Agent mode. Agent now opens a localized warning before the
  campaign starts, and campaign difficulty persists in save slots.
- Expanded Agent combat with stronger enemy aim and pressure, line-of-sight-safe
  sniper/SVD headshot threats, improved grenade awareness and validated
  actor-specific weapons and behavior.
- Added mission-specific Agent rules and HUD feedback, including the Freedom
  Memorial bomb-detonation budget, Washington Park and late-game timers,
  Aramov movement tuning, Kravitch's shotgun behavior and faster authored
  grenade users.
- Preserved checkpoint inventory and campaign state while keeping full mission
  restarts authoritative, including reliable reset of mission-only Agent
  challenge meters.
- Added English and Russian text for the Agent warning, mission rules, HUD
  meters and save-slot difficulty markers.
- Retained the public-test.23 graphics and combat work: unified distance-aware
  reticles, reliable grenade input, surface-aligned bullet impacts, localized
  wound colouring, authored night vision, SMAA Ultra, mipmapped trilinear
  filtering, dynamic lights and smoother chunk presentation.

## Agent warning

The warning identifies Agent as a PC-version addition not present in the
original game. It highlights the higher enemy threat and stricter mission
conditions without listing every rule. Continue and Back controls are shown in
both supported text languages.

## Package

- Windows x64 release with required runtime libraries and Russian locale.
- Internal per-file SHA-256 manifest and external archive checksum included.
- No game image, saves, settings, logs, cheat marker or developer artifacts.
