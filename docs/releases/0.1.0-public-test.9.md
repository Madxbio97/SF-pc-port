# Syphon Filter PC - Public Test 0.1.0-PT9

Windows x64 public-test package for the USA v1.1 release of *Syphon Filter*
(`SCUS-94240`).

## Download

- `SyphonFilterPC-0.1.0-public-test.9-win64.zip`
- `SyphonFilterPC-0.1.0-public-test.9-win64.zip.sha256`
- Verify the ZIP against the SHA-256 sidecar before extracting it.

## Highlights

- Separated first-person WASD movement from mouse/right-stick aiming and fixed
  the stale PAD/target-anchor paths that made the reticle jump.
- Smoothed high-refresh first-person movement and weapon-switch presentation
  while preserving the original 20 Hz gameplay simulation.
- Stabilized dynamic character shadows across floors, ledges and walls and
  reduced flicker when several lights affect the scene.
- Corrected transparent-world depth handling for glass and similar surfaces.
- Restored bounded typewriter animation for gameplay messages in both locales
  and retained original English sniper/night-vision scope captions.
- Removed Surface Picker code and diagnostic assets from public builds.

## Validation

- Windows PsyCross Release configured and built successfully.
- All 21 non-ROM CTest targets passed.
- Package contents, per-file hashes, external ZIP checksum and forbidden-file
  policy were verified without launching the interactive game.

## Important

The package does not contain the original game. Select a legally obtained
BIN/CUE image of *Syphon Filter* USA v1.1 in the launcher. Other revisions are
not supported.

The archive is a clean installation: it contains no saves, launcher settings,
disc image, logs or `syphon_filter_cheats` developer marker.
