## Important

The package does not contain the original game. Select a legally obtained
BIN/CUE image of *Syphon Filter* USA v1.1 in the launcher. Other revisions are
not supported.

The archive is a clean installation: it contains no saves, launcher settings,
disc image, logs or `syphon_filter_cheats` developer marker.

- Integrated launcher with CUE selection, Gabe icon and DOSSIERS bonus gallery.
- Full internal-resolution rendering, MSAA, seam-safe bilinear and independent
  anisotropic filtering.
- Improved FMV quality with the additional dithering removed.
- Restored PS1-style maps, objectives, weapon pages and pause-menu audio behavior.

- Corrected muzzle flashes, grenade presentation, sprite/particle occlusion,
