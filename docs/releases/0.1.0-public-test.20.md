# Syphon Filter PC 0.1.0-public-test.20

Windows x64 public-test candidate built on 2026-08-03.

## Changes since public-test.19

- Restored the original projected vertex-light path for the flashlight and
  moving mission spotlights, including their surface light spots.
- Light-source motion is now smooth at the display refresh rate while retaining
  the original 20 Hz simulation.
- Removed the reconstructed flashlight cone and duplicate directional light.
- Viral-detector presentation now clears immediately when aim mode ends.
