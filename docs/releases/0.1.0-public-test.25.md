# Syphon Filter PC 0.1.0-public-test.25

Windows x64 public-test candidate built on 2026-08-06.

## Changes since public-test.24

- Preserved acquired weapons and ammunition after death, checkpoint restart and
  mission failure while keeping full mission restarts authoritative.
- Completed the localized Mission Failed animation before restoring a checkpoint
  and corrected HUD, fade and scene-layer ordering around failure restarts.
- Made gameplay status backdrops adaptive in both locales, including longer
  incoming-call messages.
- Restored distant authored fire on Level 2 with correct prefetch depth, gradual
  reveal, fog integration and texture residency.
- Primed active and prefetched world chunks after checkpoint restores to prevent
  exposed interiors and layered geometry.
- Added a framed localized Select Difficulty heading.
- Removed the redundant CBDC technician-health and suspicion meters from Agent
  Mode; the original Danger indicator remains unchanged.
