# Syphon Filter PC - Public Test 0.1.0-PT6

Windows x64 public-test package for the USA v1.1 release of *Syphon Filter*
(`SCUS-94240`).

## Download

- `SyphonFilterPC-0.1.0-public-test.6-win64.zip`
- `SyphonFilterPC-0.1.0-public-test.6-win64.zip.sha256`
- Verify the ZIP against the SHA-256 sidecar before extracting it.

## Fixed in PT6

- Fixed the `invalid-renderer-snapshot` renderer/UI bridge crash in the PHARCOM
  warehouse missions.
- Preserved guest-owned world geometry and visibility while the retail streamer
  temporarily recycles an active section's auxiliary vertex-color payload.
- Added a regression test for the streaming transition and extended the
  headless environment probe beyond the reported failure frame.

## Validation

- Release build completed successfully.
- All 17 non-ROM tests passed.
- PHARCOM warehouses, PHARCOM elite guards and Warehouse 76 each completed a
  1,600-frame headless renderer probe without a bridge fault.

## Important

The package does not contain the original game. Select a legally obtained
BIN/CUE image of *Syphon Filter* USA v1.1 in the launcher. Other revisions are
not supported.

The archive is a clean installation: it contains no saves, launcher settings,
disc image, logs or `syphon_filter_cheats` developer marker.
