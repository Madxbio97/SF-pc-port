# Syphon Filter PC 0.1.0-public-test.28

Windows x64 public-test candidate built on 2026-08-07.

## Changes since public-test.27

- Added three persistent controller stick layouts, including the original
  one-stick scheme, and exposed the same setting in the launcher and pause menu.
- Stabilized DualSense input in title, save and first-person modes with
  two-stick menu navigation, hot-plug baselining and calibrated deadzones.
- Fixed native rumble output and made the vibration setting work consistently
  from both the launcher and the in-game options menu.
- Added framed, device-aware prompts to the load, difficulty and Agent warning
  screens; controller confirm/back labels now match the accepted menu buttons.
- Removed exact duplicate helper shells over authored Kazakhstan rockets and
  cisterns while retaining their gameplay state, collision and scripted links.
