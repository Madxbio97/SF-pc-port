# Syphon Filter PC - Public Test 0.1.0-PT13

Release date: 2026-07-30

## Files

- `SyphonFilterPC-0.1.0-public-test.13-win64.zip`
- `SyphonFilterPC-0.1.0-public-test.13-win64.zip.sha256`

## Changes

### Campaign and gameplay

- Restored the complete mission-completion chain: save prompt, occupied-slot
  overwrite confirmation, FMV playback and transition to the next mission.
- Preserved the campaign frontier when replaying an earlier unlocked mission.
- Resolved manual-aim ownership conflicts with auto-targeting, retained Gabe's
  final aim heading and restored crouch/diagonal movement behavior.
- Corrected danger-meter release and stabilized enemy weapon drops across the
  original 20 Hz logic and high presentation frame rates.

### Rendering

- Restored original MENU.HOG weapon artwork across the pause-menu arsenal.
- Restored both lower-subway bomb models and their resident SPFX textures.
- Fixed subway train and sign corruption by publishing one coherent SCRIM copy
  phase to every affected texture page and bank.
- Restored the virus scanner's amber X-ray presentation, infected-target reveal
  through containers and original status messages.
- Added held weapons to character shadows, stabilized multi-light selection and
  floor/wall projection, and kept emissive lamps at authored brightness.
- Added close-camera fade for Gabe and restored reticle/world-label reveal
  animation. Letterbox bars now appear only during mission introductions.
- Cached unchanged lighting work at the 20 Hz guest tick for steadier 60–240 FPS.

### Audio, UI and localization

- Reworked native audio timing and VAB one-shot decoding to reduce latency,
  underruns, skipped samples and restart artifacts.
- Restored the voice-volume preview sound.
- Kept original English optic captions in the Russian pack and prevented
  Russian objective text from leaking into the English interface.
- Added focused regression tests for the new campaign, renderer, bridge,
  localization and audio behavior.

## Validation

- Windows MSVC Release build and full non-ROM test suite.
- Windows PsyCross Release build, full non-ROM suite and supported USA v1.1
  ROM probes.
- Release manifest, executable parity, internal/external SHA-256 and
  forbidden-file audit.

## Compatibility

The package requires a legally obtained BIN/CUE image of *Syphon Filter* USA
v1.1 (`SCUS-94240`). It contains no game image, saves, settings or cheat marker.
The release remains a public test and may contain compatibility issues.
